# Буферизованный UART

[BufferedUart](BufferedUart.h) — отключаемый UART0/VFS адаптер
`NES_APP_UART_BULK_TX`. `__wrap_*` — реальные linker entrypoints. ISR,
ранний старт и чужие дескрипторы сохраняют исходный путь.

Статические VFS/control живут до перезапуска. Mutex сериализует TX;
ограниченные пачки/частичный CRLF сохраняют принятый префикс. `fsync`
завершает ring/аппаратный TX до deadline с уступкой RTOS. Внутри proxy нельзя
рекурсивно журналировать через тот же канал.

Подробная строка `NES_FRAME_LOOP_METRICS` хранится в одном слоте Main.
Приложение пытается отправить её целиком при пустой очереди TX. Замки stdout
и VFS берутся без ожидания в том же порядке, что у обычной печати.
Если слот занят весь период отчёта, предыдущая строка передаётся штатно
перед заменой. Поколение и номера кадров записаны до отправки.

Частичная запись/timeout возвращаются caller, не доказывая завершения Worker.
Буферизация не меняет input edges и replay quarantine. Проверки: частичные
записи/CRLF/ошибки и target VFS/linker build; команды — в общем руководстве.
