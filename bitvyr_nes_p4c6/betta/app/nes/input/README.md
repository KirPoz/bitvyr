# Прикладной ввод NES

GT911/BLE/HID находится в Board. Main объединяет touch, контроллер и UART-маску,
затем передаёт принятую маску в Worker. `$4016/$4017` эмулирует Machine.

[TouchOverlap.inl](TouchOverlap.inl) — отключаемый ранний опрос внутри App.
Он сохраняет контакт/длительность, но не создаёт второй I2C owner/задачу;
действия выполняются в `NesApp::frame`.

Снимок относится к своему кадру. Stale контакт не становится свежим нажатием,
разрыв отпускает кнопки, смена режима очищает неподходящий ввод. Проверки:
HID/UI fixtures и отдельное фактическое управление на плате.
