# Точка входа

`app_main` в [main.cpp](main.cpp) создаёт один статический долгоживущий
`nes::app::NesApp` и передаёт ему управление. Объект живёт до перезапуска;
возврат Main либо timeout не доказывает завершения Worker и не разрешает
разрушать заимствования.

[P4CacheHandoff.cpp](P4CacheHandoff.cpp) — ранний аппаратный адаптер HP ICache P4.
Он сохраняет исходный SDK high-performance-mode вызов, проверяет границы IRAM,
использует ROM invalidate и не инвалидирует DCache. До старта CPU1 адаптер имеет
одного writer. Ошибка диапазона/invalidate приводит к ROM reset; обхода защиты
памяти и изменения частот здесь нет. Переносимое Core этот файл не включает.

Проверка: SDK-сборка и ABI main/App/Core; runtime-стек, cache handoff и аппаратное
владение проверяются отдельно. Правка комментариев не является новой аппаратной
квалификацией.
