# Bitvyr NES P4+C6 · Beta 0.2

Портативная NES-консоль для Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3. Загрузите `.nes` или ZIP в `nes_rom` на SD-карте, выберите игру и играйте с сенсорных кнопок или Xbox Series. Активный картридж загружается в оперативную память. P4 исполняет игру и выводит кадры, C6 рассчитывает звук.

На контрольном образе `6040788b` все 114 измерительных окон в 38 маршрутах попали в диапазон 59,5–60,5 FPS. Это скорость подачи кадров драйверу LCD. В таблице для каждой игры указаны CRC картриджа, кадры маршрута и разброс. [Результаты и хеши образов](docs/04-results.md)
