# Скорость подачи кадров в 38 играх

23 ноября 2026 года на Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3 проверены 38 закреплённых маршрутов. **Все 114 окон дали от 59,571 до 60,215 FPS.** P4 работал на 400 МГц, в настройках выбран NTSC и громкость 7, включены синтез PCM на C6 и вывод на динамик. Каждый маршрут воспроизводит записанный ввод, а в измерение попадают последние 360 указанных кадров.

## Как читать таблицу

Минимум и максимум относятся к трём последовательным окнам по 120 кадров. Среднее равно 360 подачам драйверу LCD, делённым на время всей сцены по часам платы. Это измеряет темп подачи в заданном участке игры. Для физической панели, покадровых задержек и остальных уровней нужны другие измерения. CRC32 позволяет найти точное издание, включая переводы.

| ESP32-C6, ELF | `c2660fac172c216b5a26424dd993af0377747b5688ae4bcaf739668465738d05` |

ELF `6040788b` использует закреплённое размещение горячих функций. Чистая сборка исходников штатным линкером ESP-IDF 6.1 дала другой ELF (`8028f1ec`), прошла Full Clean, Build и 40 нативных тестов. Таблица выше относится к образу `6040788b`.

Рецепт C6 проверен повторной сборкой в чистом каталоге. Проверены все 36 внешних входов, линковка с контроллером и итоговый BIN. Новая сборка дала ELF `cf0d161d260b52f22f029f20d34be891061bb1fcbda5c856b3a2715c2e89af43`. На плате измеряли C6 `c2660fac`.

По ID доступны все 38 ROM, границы окон, записанный ввод, счётчики CPU/C6 и исходные отметки времени. Запускайте из корня репозитория.

```powershell
python -B tools/experiments.py --id p4c6-autonomous-6040-catalog-38-20261123
python -B tools/experiments.py --id p4c6-autonomous-6040-older-repeated-20261123
```
