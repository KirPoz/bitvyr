# Консоль и совместимость

Bitvyr исполняет игры NES на Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3. Для пополнения библиотеки достаточно скопировать файлы на SD. Программа распаковывает выбранный картридж в PSRAM при запуске. На внутренней flash хранятся прошивка и настройки.

| Узел | Конфигурация выпуска |
| --- | --- |
| ESP32-P4 | Два вычислительных ядра, профиль 400 МГц |
| ESP32-C6 | Синтез PCM 48 кГц и транспорт Bluetooth геймпада по SDIO |
| Экран | NES 256×240, игровая область 640×480 на панели 800×480, кнопки по краям |
| Диск | SD FAT32, каталог `nes_rom`, распакованные `.nes` и ZIP с NES-образом |
| Управление | Мультитач GT911 и Xbox Series по Bluetooth |
| Картриджи | Мапперы 0, 1, 2, 3, 4, 5, 7, 69, 71, 85. Для маппера 160 поддерживается вариант Aladdin с CRC32 `af74d272` |

Маппер задаёт схему банков памяти и, в зависимости от картриджа, прерывания или расширенный звук. Название игры иногда совпадает у изданий на разных платах. В таблице замеров ROM определяет CRC32. [Измеренные игры](04-results.md) · [Установка и первый запуск](03-guide.md)
