# Связанный вывод MMC5

`CoupledVideoPipeline` исполняет поток Thin на CPU0. Worker на CPU1 владеет
`Machine` и публикует через `ThinBridge` готовые порции событий. Полный ключ
содержит ROM, поколение, слот, кадр, ввод и границу гостевого времени.
Ответ на чтение MMIO соответствует одному запросу. Итоговое подтверждение
кадра приходит после обработки всех принятых порций.

Кольцо Thin содержит восемь слотов. Перед запуском Main выделяет горячие
объекты и проверяет весь диапазон памяти. В ожидании новой порции Main
обслуживает дисплей. Подтверждение неизменяемого аудиосреза разрешает
обработку только этого пакета и сохраняет владение исходными данными.

`AsyncPresent` освобождает источник RGB после чтения PPA. LCD освобождает
буфер вывода отдельным событием. При ошибке сеанса Main сохраняет ресурсы
до фактического завершения Worker, сброса аудиоочереди и C6 UNBIND.

Нативные тесты сверяют CPU, IRQ, RAM, RGB и PCM. Размещение горячих объектов,
остаток стека и продвижение очередей проверяются на P4.
