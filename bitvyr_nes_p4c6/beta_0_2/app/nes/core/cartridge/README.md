# Картридж и мапперы

[Cartridge](Cartridge.h) валидирует ROM/NES2, выбирает mapper и связывает PRG/CHR
страницы. ROM заимствуется у App; RAM и банковые окна принадлежат картриджу.
Копирование запрещено из-за идентичности страниц и аренд. Смена банков и загрузка
инвалидируют views/эпохи. Неизвестная карта не подменяется другим mapper.

Mirroring, IRQ, CHR dirty, MMC5 RD/ExRAM/split зависят от настоящего порядка
обращений. Аудиодолг закрывается до влияющей записи или наблюдения. Guest IRQ
и PCM-стробы не откладываются произвольно. Loader проверяет размер RAM/NVRAM,
backing и поддерживаемый submapper до публикации картриджа.

MMC5 разделён на [Mmc5](Mmc5.h), [Mmc5Audio](Mmc5Audio.h) и CartridgeMmc5.
[Mmc5RasterPlan](Mmc5RasterPlan.h) заимствует CHR/CIRAM/ExRAM и подготовленную
policy только для синхронного grant. Успешная подготовка сама по себе не даёт
quiet-сертификата. Typed tile helpers сохраняют Name/attribute, physical offset,
банки и защёлки; caller отдельно материализует исходные цифровые переходы.

Raw MMC5 audio `sample/levels/status` остаётся цифровым эталоном. Portable
selected provider отдельно усредняет разрешённые carrier-фронты; PCM, frame,
envelope, IRQ и MMIO остаются барьерами. Его результат не является raw DAC.
[Sunsoft5BAudio](Sunsoft5BAudio.h) и [Vrc7Audio](Vrc7Audio.h) имеют отдельные
CPU-clocked модели. [Vrc7WriteTape](Vrc7WriteTape.h) связывает immutable writes
с точным output cut; частичная либо повреждённая tape не публикуется.

Mapper 7 (AxROM) принимает NES 2.0 submapper 1 и 2. В первом регистр
банка получает значение CPU напрямую. Во втором регистр получает AND
с байтом текущего PRG ROM по тому же адресу. Это определяет номер банка
и страницу CIRAM. [Схема AxROM](https://www.nesdev.org/wiki/INES_Mapper_007)

Mapper 71 (Camerica BF9093/BF9097) переключает нижнее окно PRG 16 КиБ записью
по $C000–$FFFF. Верхнее окно закреплено за последним банком. CHR занимает
одно окно 8 КиБ, а чтение $6000–$7FFF возвращает открытую шину. На NES 2.0
submapper 1 запись по $8000–$9FFF выбирает площадку CIRAM битом 4. Для iNES
до записи по $9000–$9FFF действует зеркалирование из заголовка.
[Схема mapper 71](https://www.nesdev.org/wiki/INES_Mapper_071)

MMC5 адресует CHR до следующей степени двух. Для образа с последней
неполной областью недостающие KiB возвращают $FF. Размер и CRC файла остаются
исходными. При таком размере producer публикует уже прочитанные байты в
видеопакете, поэтому renderer не разыменовывает адреса пустой области.
[Правило заполнения CHR в FCEUX](https://github.com/TASEmulators/fceux/blob/master/src/ines.cpp)

### Контракты операций

| Методы | Действие |
| --- | --- |
| `Cartridge::cpuRead`, `readMmc5Cpu` | Чтение CPU использует выбранную страницу или значение открытой шины. MMC5 считает строб чтения и передаёт байт расширению PCM. |
| `mmc3Write`, `writeVrc7` | Чётность и диапазон адреса MMC3 выбирают банк, зеркалирование, режим PRG RAM или IRQ. VRC7 декодирует регистр по разводке платы и передаёт время в тактах CPU для FM. |
| `clockMmc5Cpu`, `mmc5Irq` | Цифровая часть и аудио MMC5 получают общее число M2. Линия IRQ объединяет детектор строк и PCM. |
| `observeMmc5Read`, `observeMmc5Write`, `expansionSample` | Наблюдатели передают активному MMC5 адрес и байт фактической операции. Уровень расширения берётся из выбранного маппера, а внешний VRC7 обрабатывает собственный рендерер. |
| `Mmc5::attach`, `detach`, `powerOn`, `resetSignal` | Привязка проверяет размеры PRG/CHR/SRAM до публикации указателей. Отключение очищает указатели и состояние кадра. Включение задаёт регистры и очищает ExRAM, сигнал Reset восстанавливает режимы банков и защиту записи. |
| `decodePrg`, `ramOffset`, `prgPage`, `writablePrg` | Адрес CPU разбирается на восьмикилобайтный банк PRG и смещение; для RAM учитываются линии SRAM. Страница возвращается, если существует, а запись требует открытой защиты. |
| `cpuPeek`, `cpuRead`, `cpuReadStrobe`, `cpuWrite` | Peek не меняет состояние. Чтение $5204 подтверждает IRQ. Вектор NMI либо установленный vblank при чтении $2002 закрывает кадр. Запись применяет банковые, RAM и регистровые эффекты. |
| `endFrame`, `clockCpu`, `detectScanline`, `ppuReadStrobe` | Детектор строк потребляет реальные сигналы чтения PPU и такты M2. При паузе чтений закрывается кадр; граница строки обновляет счётчик и сравнение IRQ. Чтение палитры остаётся внутри PPU. |
| `nametablePeek`, `beginBackground`, `chrOffset`, `ppuRead`, `ppuWrite` | Таблица имён читается из CIRAM, ExRAM или режима заполнения. Чтение имени фиксирует расширенные атрибуты и вертикальный сплит для вычисления CHR-адреса. Запись меняет нужную страницу CIRAM/ExRAM. |
| `Mmc5Audio::sample` | Уровни двух импульсов и PCM суммируются с их весами Q16 и возвращаются в шкале микшера. |

Состав алгоритмов задан исходниками и [CMakeLists.txt](../CMakeLists.txt).
Нативные тесты проверяют загрузчик, границы банков, IRQ, MMIO, звуковое расширение и пометки изменённой памяти. Для проверки скорости используются закреплённые маршруты с ROM на SD.
