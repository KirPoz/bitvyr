# Аудио приложения

CPU1 фиксирует изменения цифровых каналов APU. CPU0 передаёт согласованный срез C6 и получает PCM. Для MMC5 подготовленный пакет может уйти до окончательного подтверждения кадра. В двухслотовом конвейере `Frame` CPU0 получает доступ к опубликованному пакету после завершения задания Worker.

`PcmStreamGuard` на CPU0 проверяет сеанс, эпоху, порядок кадров, фазу синтеза и число сэмплов. Проверка учитывает, что I2S может принять часть предложенного буфера. Источник освобождается после соответствующего подтверждения. На смене ROM приложение завершает очередь и отвязывает старый сеанс C6.
