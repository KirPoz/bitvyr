# Общие таблицы DEFLATE

[DeflateTables.h](DeflateTables.h) содержит SDK-free C++17 таблицы Хаффмана
и константы RFC1951 для ZIP/replay. Core и BSP от него не зависят.

`Huffman::build` проверяет пустое/полное/неполное/переполненное дерево; caller
ограничивает алфавит 288 символами. `decode` заимствует источник битов: I/O,
усечение и отмена сохраняют свою ошибку, а не становятся «плохим кодом».

Helper не владеет FILE, ROM или history ring. Их лимиты, CRC и освобождение
остаются у декодера; общие таблицы не объединяют независимые состояния.
Проверки: синтетические ZIP/DEFLATE и независимый Python zlib-эталон.
