# Bitvyr NES P4+C6

Проект ESP-IDF 6.1 для ESP32-P4. P4 готовит цифровые события APU, C6 рассчитывает PCM 48 кГц и возвращает его по Hosted SDIO. P4 передаёт PCM в I2S. Согласованный C6 worker обслуживает одновременно звук и Bluetooth.

## Betta 0.1

Исходники выпуска отмечены тегом `betta-0.1`. Версия в заголовке прошивки
— `0.1-beta`. Редакция P4+C6 включает
группировку точек PPU до ближайшей границы IRQ MMC3. В парном замере
оптимизация освободила около **2,8 мс CPU1 на кадр**.

На плате проверены все семь игр MMC3 из каталога и ещё три контрольные
сцены. Во всех 30 окнах по 120 кадров скорость подачи на дисплей составила
**59,938–60,143 FPS**. В бою **TMNT II** минимум вырос с **53,859 до
60,070 FPS**, среднее составило **60,118 FPS**.

[Таблица замеров выпуска и покрытие каталога](docs/04-results.md).
Для остальных 16 игр доступны данные предыдущего рабочего образа.
Первый бой **Just Breed EN** в отдельной диагностической прошивке дал
минимум **57,059 FPS**. [Замеры диагностических сборок](../beta/docs/04-results.md)

Сборка ESP-IDF 6.1 и 40 нативных тестов прошли. Тест MMC3 проверяет
граничный случай IRQ в начале строки 240.
SHA-256 образа, проверенного на десяти сценах, —
`d37c6e20943b0fb36afb1d9cb53d75cc692d70957633ad5211d22e9c06f757b7`.
