# Замеры P4+C6 Betta 0.1

## Замер рабочего профиля

21 ноября 2026 года на плате проверено **10 сцен** рабочего профиля с оптимизацией MMC3 из `0b84d25`. Во всех **30 окнах** получено **59,938–60,143 FPS**. В бою TMNT II минимум составил **60,070 FPS** при среднем **60,118 FPS**. Минимум того же маршрута на предыдущем рабочем образе составлял **53,859 FPS**.

У каждой сцены 360 гостевых кадров с записанным вводом. Среднее рассчитано по времени платы за всю сцену, минимум и максимум — по трём окнам по 120 кадров. FPS показывает скорость подачи кадров драйверу дисплея. P4 работал на 400 МГц, режим NTSC. Оптимизация вошла в тег `betta-0.1`, папка выпуска — `beta_0_1`. SHA-256 проверенного образа — `d37c6e20943b0fb36afb1d9cb53d75cc692d70957633ad5211d22e9c06f757b7`.
