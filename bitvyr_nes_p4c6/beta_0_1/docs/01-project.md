# Bitvyr NES P4+C6

Bitvyr запускает NES-картриджи с карты FAT32. Библиотека лежит в `/nes_rom`. Одна открытая ROM занимает место в PSRAM на время игры. Обычные картриджи используют Frame и два слота. MMC5 передаёт события Thin PPU через ограниченный Coupled-конвейер.

| Узел | Конфигурация |
|---|---|
| Плата | Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3 |
| P4 | CPU 400 МГц в основном профиле, Flash 80 МГц, PSRAM 200 МГц |
| Экран | 800×480, RGB565, PPA и MIPI-DSI |
| Игровое изображение | 256×240, цвет формируется на CPU0 |
| Ввод | GT911 и Xbox Series по Bluetooth |
| Картриджи | Мапперы 0, 1, 2, 3, 4, 5, 7, 69 и 85. Для маппера 160 загрузчик распознаёт вариант Aladdin с CRC32 `af74d272` |
| Звук | PCM 48 кГц на C6, вывод через I2S P4 |

P4 готовит цифровые события APU, C6 рассчитывает PCM 48 кГц и возвращает его по Hosted SDIO. P4 передаёт PCM в I2S. Согласованный C6 worker обслуживает одновременно звук и Bluetooth. [Frame/Coupled и звук на C6](02-architecture.md) · [Сборка](03-guide.md) · [Игровые замеры](04-results.md)
