# Дисплей и PPA

[Display.cpp](Display.cpp) настраивает DSI/DPI и ST7701. Физическое разрешение
480×800 представлено приложению как 800×480. PPA масштабирует и поворачивает
игровой RGB565 из 256×240; боковые панели отведены управлению. [Text.cpp](Text.cpp)
рисует глифы из `Font5x7.h`.

Board владеет источниками и буферами вывода. PPA завершает чтение источника до
перезаписи RGB565. LCD отдельно сигнализирует, когда можно снова использовать
целевой буфер. При тайм-ауте Board удерживает активное заимствование.

`GameBarsDirty.h` хранит по два изменённых прямоугольника для каждого буфера
LCD. Main отмечает изменения глифов, кнопок и FPS. При подготовке кадра
`prepareFrame` копирует только отмеченные части панелей с поворотом на 270°.
При смене владельца, отсутствии достоверных границ или пересечении диапазонов
копируются обе панели. Синхронизация кэша охватывает полные диапазоны панелей.

Нативные проверки сравнивают геометрию, копирование и порядок завершений.
Развёртку дисплея и DMA проверяют на плате.
