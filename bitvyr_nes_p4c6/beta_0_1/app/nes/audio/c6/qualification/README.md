# Допуск звука и телеметрия

`C6BatchImage.h` задаёт допустимый SHA-256 ELF worker C6. Для локального образа SHA задаётся через `NES_C6_WORKER_SHA256`. Wire capabilities и полный ключ HELLO проверяются вместе с SHA.
Main проверяет поколение сеанса, время и длину PCM, затем выдаёт подтверждённые отсчёты в I2S.
`MainPumpCost.h` измеряет полное время вызова Main до возврата, включая прерывания.
