# Аудиосопроцессор ESP32-C6

P4 посылает по SDIO цифровые события APU. Задача C6 рассчитывает PCM 48 кГц и возвращает пакет P4 для вывода через I2S. По тому же физическому каналу ESP-Hosted передаёт HCI геймпада. Сеанс, номер запроса и эпоха транспорта позволяют сопоставить возвращённый PCM с пакетом отправителя.

| Каталог | Назначение |
| --- | --- |
| `src`, `apu_fixed` | Приём и разбор запроса, синтез и фильтрация PCM, ответ P4 |
| `project`, `config` | Плата, ESP-Hosted, загрузочная конфигурация и разделы flash C6 |
| `recipe`, `provenance`, `patches`, `LICENSES` | Порядок сборки, контрольные суммы, происхождение и лицензии зависимостей |
| `bluetooth_audio`, `tools` | Сборка совместимого worker для Beta 0.2 из закреплённых внешних входов |

Владелец слота удерживает буфер до подтверждения передачи с совпавшим ключом запроса. При смене игры P4 дожидается завершения очередей и отвязывает worker. Для сборки нужен ESP-IDF 6.1, инструменты Windows и checkout исходников транспорта. [Сборка worker](bluetooth_audio/README.md) · [Настройка P4 и установка](../../docs/03-guide.md)
