# Ядро NES

`Machine` объединяет 6502, шину, PPU, APU и контроллер картриджа. Ядро на C++17 используется в прошивке и нативных проверках. На плате состояние машины принадлежит Worker на CPU1. Память загруженного ROM принадлежит приложению и должна оставаться доступной весь сеанс.

| Узел | Граница ответственности |
| --- | --- |
| [CPU](cpu/README.md) | Декодирование, адресация, регистры, исполнение на тактах гостя |
| [Картридж](cartridge/README.md) | Отображение PRG/CHR, IRQ и звуковые расширения плат картриджей |
| [PPU](ppu/README.md) | Регистры, строки, выборки фона и спрайтов, события для сборки цвета |
| [APU](apu/README.md) | Цифровые состояния звуковых каналов, DMC, пакет для синтеза |

CPU и PPU могут продвинуться сразу на несколько тактов, если заранее известна следующая наблюдаемая граница. Её задают обращения к регистрам, DMA/DMC, выборка маппера, IRQ или NMI. Для передачи на CPU0 используются опубликованные данные с номером сеанса, кадра и слота. При смене картриджа приложение сначала завершает работу с его памятью.
