# Формат строк PPU для C6

Рецепт C6 собирает закреплённый по SHA файл `ResolvedColourCodec.cpp` вместе
с его заголовком. Кодек задаёт формат little-endian независимо от ABI.

- `encodeSeed` записывает регион, 32 байта палитры и восемь описаний спрайтов.
  `decodeSeed` проверяет версию, длину и биты флагов перед обновлением результата.
- `encodeRun` проверяет состояние сдвиговых регистров, атрибуты и ёмкость
  буфера, затем пишет заголовок и три байта на тайл. `decodeRun` сверяет
  число тайлов, зарезервированные байты и точную длину, проверяет состояние
  на временном объекте и публикует его целиком при успехе.
