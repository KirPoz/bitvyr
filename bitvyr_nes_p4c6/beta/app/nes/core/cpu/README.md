# CPU 6502

[Cpu6502](Cpu6502.h) исполняет инструкции, формирует чтения, записи и промежуточные обращения на шине. [Таблица опкодов](OpcodeTable.inl) задаёт декодирование. [АЛУ](CpuAlu.inl) обновляет регистры и флаги процессора.

[CpuQuietBlock.cpp](CpuQuietBlock.cpp) исполняет последовательность инструкций в пределах разрешённого машиной числа тактов. Временное окно `RomWindow` указывает на текущую страницу PRG. Смена банка, переход через непроверенную страницу, предстоящее IRQ, DMA/DMC, доступ к регистру или исчерпание бюджета возвращают исполнение обычному пошаговому пути.

Для MMC5 сокращение петли ожидания требует совпадения её байтов и заранее подтверждённого результата чтения STATUS. Ядро учитывает число исполненных инструкций, флаги, адрес следующей инструкции и точный такт конца участка. [Связь с PPU и картриджем](../../../../docs/02-architecture.md)
