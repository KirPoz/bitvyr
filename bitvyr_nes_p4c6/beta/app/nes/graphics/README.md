# Экран, меню и сенсорные кнопки

`MenuLayout.h`, `PauseMenu.h` и `GameControls.h` задают общую геометрию для рисования и определения касаний. `GameChrome.h` рисует кнопки, стрелки, индикатор FPS и подсветку текущего нажатия. Игровая область занимает центр логического экрана 800×480, органы управления размещаются по краям.

`PresentationRate.h` считает скорость передачи готовых кадров драйверу. Рисование помечает изменённые области боковых панелей. Драйвер платы отвечает за отсечение прямоугольников, размещение буферов, поворот через PPA и момент повторного использования памяти.
