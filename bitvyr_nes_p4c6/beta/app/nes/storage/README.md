# Библиотека игр на SD

[GameLibrary](GameLibrary.h) индексирует `.nes`, ZIP Store/Deflate и подпапки
`/sdcard/nes_rom`. Несколько ROM в ZIP дают несколько записей.
[ZipArchive](ZipArchive.h) загружает выбранный образ в PSRAM без записи на SD/Flash.

Индекс динамический, без лимита 64 игры; остаются память/пути/глубина обхода.
Main владеет индексом/загрузкой, handles не переживают вызов. Scan меняет
поколение выбора. CRC/размеры/изменение файла проверяются до принятия;
ошибка не публикует частичный ROM. После remount нужен новый `open()`.

Активную ROM освобождает App после завершения всех заимствований. Mapper
разбирает Core; `snes_rom` не реализует SNES. Постоянные игровые сохранения
не реализованы. Проверки: synthetic catalog/ZIP/prefix I/O и отдельно реальная SD.
