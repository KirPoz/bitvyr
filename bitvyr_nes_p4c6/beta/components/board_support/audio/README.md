# Аудиовывод платы

[Audio.cpp](Audio.cpp) настраивает ES8311/I2S0 на 48 кГц/16 бит; mono PCM
дублируется в два слота. ES7210/микрофоны не инициализируются.

Main подаёт PCM, кодек/DMA принадлежат Board. Старт оставляет PA выключенным
и DAC приглушённым, затем App применяет сохранённую громкость. Ошибка I2C
запрашивает тихий режим; кривая не даёт положительное усиление и не меняет NVS.

Шесть DMA-блоков по 256 стереокадров ограничивают очередь. Поздняя подача даёт
нули, не повтор старого звука. Partial write/timeout сообщаются caller;
accepted PCM и завершённая DMA-передача различны. `audioStats` не доказывает
непрерывность сеанса. SDK/счётчики и физический динамик проверяются отдельно.
