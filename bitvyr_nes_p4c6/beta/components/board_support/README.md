# Аппаратный адаптер платы

[Board.h](include/board/Board.h) объявляет интерфейс ESP32-P4-WIFI6-Touch-LCD-4.3.
Main на CPU0 владеет [дисплеем](display/README.md), [вводом](input/README.md),
[звуком](audio/README.md) и [SD](storage/README.md). Скрытое состояние и
дескрипторы периферии принадлежат Board. ESP-Hosted обслуживает связь с C6.

Игровой A/B-вывод передаёт неизменяемый RGB565 по полному ключу заимствования.
A — зарегистрированный буфер в PSRAM, B — штатный буфер Board. Регистрация
проверяет границы, выравнивание, раздельность диапазонов, три буфера LCD и
отключённое шифрование Flash. При активной регистрации Board отдаёт игровые
буферы через этот интерфейс. Меню использует отдельный логический буфер.

PPA и LCD завершают разные операции. До завершения PPA нельзя перезаписать
источник, а до завершения LCD — повторно использовать его целевой буфер.
При тайм-ауте текущий ключ и заимствование остаются у Board. Успешный
`finishBorrowedGamePresent` возвращает источник после подачи кадра.

`test/HostHidTests.cpp` проверяет разбор пакетов контроллера в нативной
сборке. Проверки геометрии и заимствования находятся в общем наборе tests.
