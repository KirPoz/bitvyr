# Общие правила сборки

| Модуль | Назначение |
|---|---|
| `NesCxxStandard.cmake` | C++17, согласованные параметры компиляции и отчёт об использовании стека |
| `NesNativeTests.cmake` | Предупреждения и активные проверки C++ в нативных тестах Release |
| `P4SdkCompatibility.cmake` | Отложенный запуск Hosted и настройка sysroot Picolibc на Windows |
| `P4CpuClock.cmake` | CPU 400/360 МГц в обоих проектах P4. Для ревизий до 3 локальная RTC-копия создаётся в `build/generated` из закреплённого исходника ESP-IDF 6.1 |

Эти модули подключаются во всех трёх редакциях Bitvyr. Правила линковки и список файлов каждого приложения находятся в его собственной папке.
