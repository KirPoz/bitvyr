# Журнал измерений Bitvyr

Карточка опыта хранит дату, проверенную сборку, условия, результат и решение. У игрового прогона есть CRC картриджа, регион, ввод, границы кадров и отметки времени платы. Исторические записи об артефактах указывают тип свидетельства и источник даты. Подготовленная конфигурация сама по себе не подтверждает запуск.

| Файл | Содержимое |
| --- | --- |
| [experiments.json](../experiments.json) | Действующий журнал, последние события и ссылки на составные части |
| [history.json](history.json) | Предыдущие события, ручные отчёты и карточки сохранившихся артефактов |
| [evidence.json](evidence.json) | Индексы по SHA-256, проекции отчётов и повторно используемые фрагменты |

Из корня репозитория можно выгрузить все события вместе с данными в **один самодостаточный JSON**. Команда также проверяет уникальность ID. Чтение по SHA раскрывает связанный отчёт, сохранённый результат или сведения о наличии исходного свидетельства.

```powershell
python -B tools/experiments.py --export .local/experiments-full.json
python -B tools/experiments.py --file .local/experiments-full.json --date 2026-11-23 --limit 500
python -B tools/experiments.py --id p4c6-autonomous-6040-catalog-38-20261123
python -B tools/experiments.py --id p4c6-autonomous-6040-older-repeated-20261123
python -B tools/experiments.py --sha 70de975f27b8c14355ce2a8837fec8def4d5aff7037153a45b3926f5098797de
```

В срезе перед выпуском Beta 0.2 собрано 3 282 записи с датами в поле `date` от 8 до 23 ноября 2026 года. Из них 1 485 — индексные карточки. Подробные показатели для 38 маршрутов рассчитаны по 114 последовательным окнам, всего 13 680 подач драйверу LCD. Для сравнения разных образов используйте тот же ROM, регион, ввод, интервал и звук.
