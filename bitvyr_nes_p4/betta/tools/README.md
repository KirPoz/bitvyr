# Инструменты разработчика

`Invoke-Idf.ps1` вызывает выбранное активированное ESP-IDF6.1 и работает только с локальным `build`. `-Overclock ON/OFF` выбирает единственный проектный параметр частоты. SDK и пользовательские настройки IDE он не переписывает.

Native-проверки запускаются CMake/CTest из `tests/host`. Аппаратные проверки выполняются отдельно после успешной SDK-сборки и проверки фактического COM-порта.
