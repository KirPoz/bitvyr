# Старт прошивки

app_main создаёт статический NesApp. P4CacheHandoff согласует HP ICache после bootloader до первого SDK HPM-вызова.

Ранний startup выполняется CPU0 до запуска CPU1; приложение затем использует обычное RTOS-владение.

При ошибке раннего invalidate выполняется ROM-reset. SDK-файлы и DCache не переписываются.

ESP-IDF6.1 и nes; проверка — чистая загрузка нового образа на фактической ревизии P4.
