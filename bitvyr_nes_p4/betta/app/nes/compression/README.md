# Канонические таблицы DEFLATE

DeflateTables хранит общие ограничения и канонические Huffman-коды ZIP-декодера.

Чистый C++17 без SDK и глобального изменяемого состояния.

Буферы принадлежат декодеру; проверяются длины, переполнение таблиц и недопустимые коды.

Стандартная библиотека. Проверка — ZIP fixtures с корректными и повреждёнными потоками.
