# Настройки консоли

ConsoleSettings задаёт тихие defaults и явный16-байтовый формат; SettingsStore читает и сохраняет NVS.

Только Main; значения региона применяются на границе остановленной игры.

CRC/версия/диапазоны проверяются до принятия blob. Ошибка записи оставляет dirty-состояние и не стирает NVS.

NVS только в SettingsStore.cpp. Проверка — сериализация, CRC и ограничения значений native-тестом.
