# Ранний опрос сенсора

TouchOverlap читает GT911 на Main во время вычисления Worker и сохраняет краткоживущий снимок контактов.

I2C остаётся у CPU0; Worker не читает сенсор и получает только фиксированную NES-маску кадра.

Снимок имеет возраст: устаревший результат читается повторно. Новая задача и неограниченная очередь не создаются.

Board и esp_timer; проверка — возраст контактов и аппаратное управление.
