# SDMMC и FAT

Storage.cpp монтирует штатный SD-слот и предоставляет состояние носителя, не меняя разделы.

Только Main; библиотека обращается через обычные файловые API после успешного mount.

Питание/карта/файловая система проверяются раздельно. Ошибка не вызывает форматирование; карта принадлежит BoardState.

SDMMC/FATFS SDK; аппаратная проверка FAT32, ZIP и повторного чтения.
