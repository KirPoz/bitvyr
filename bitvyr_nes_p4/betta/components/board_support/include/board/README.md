# Контракты Board и Bluetooth

Заголовки описывают инициализацию, кадровую подачу, звук, сенсор и опубликованный Xbox-ввод.

Board API вызывается Main; BluetoothInput управляет собственным транспортным контекстом.

Публичные указатели не передают владение. Ошибки и readiness отдельных устройств доступны явно.

ESP-типы ограничены адаптером, переносимый Machine независим от Board.
