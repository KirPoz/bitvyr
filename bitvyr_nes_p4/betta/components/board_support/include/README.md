# Публичные аппаратные интерфейсы

board/Board.h и board/BluetoothInput.h — единственный интерфейс App к драйверам.

Контракты методов фиксируют Main/Bluetooth владение; Core эти заголовки не включает.

Буферы возвращаются заимствованными; callers соблюдают sourceDone/join и время жизни Board.

Реализации — в соседних пакетах; проверка — SDK-сборка всех consumers.
