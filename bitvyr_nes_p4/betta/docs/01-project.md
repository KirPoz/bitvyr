# Bitvyr NES P4

Bitvyr запускает NES-картриджи с карты FAT32. Библиотека лежит в `/nes_rom`. Одна открытая ROM занимает место в PSRAM на время игры. Кадры всех поддерживаемых картриджей передаются через Frame с двумя слотами.

| Узел | Конфигурация |
|---|---|
| Плата | Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3 |
| P4 | CPU 400 МГц в основном профиле, Flash 80 МГц, PSRAM 200 МГц |
| Экран | 800×480, RGB565, PPA и MIPI-DSI |
| Игровое изображение | 256×240, цвет формируется на CPU0 |
| Ввод | GT911 и Xbox Series по Bluetooth |
| Картриджи | Mapper 0, 1, 2, 3, 4, 5, 7, 69, 85 и 160 |
| Звук | Локальный PCM на P4, вывод через I2S |

CPU0 строит PCM из событий APU и выдаёт его в I2S. ESP32-C6 обслуживает Bluetooth через Hosted SDIO. [Frame и локальный звук](02-architecture.md) · [Сборка](03-guide.md) · [Игровые замеры](04-results.md)
