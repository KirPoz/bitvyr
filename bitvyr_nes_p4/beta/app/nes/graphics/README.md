# Экранные элементы

MenuLayout, PauseMenu, GameControls и GameChrome задают геометрию, попадания, стрелки и FPS.

Main рисует отдельные UI/боковые буферы; горячий producer их не изменяет.

Кнопки остаются за пределами центральной640×480 области. Функции не владеют переданными пикселями; прямоугольники полуоткрытые.

Core Types и интерфейс Board; шаблонные fake Board позволяют проверить UI без SDK.
