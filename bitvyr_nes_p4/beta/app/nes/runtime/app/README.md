# Части прикладного координатора

Все фрагменты включаются по порядку в NesApp.cpp после общего состояния владельца. Единица компиляции, владельцы ресурсов и порядок C++-операций остаются общими.

| Фрагмент | Ответственность |
|---|---|
| VideoSetup | Допуск backend и цифрового audio на reset-cut |
| FrameVideo | Передача Frame-слотов и приём завершённого RGB/PCM |
| Worker | Задания CPU1, семафоры, явное завершение |
| Session | Поколения, pause, pacing и счётчики |
| StopPlayback | Настоящий join/drain и release Frame-владельца перед возвратом в Library |
| Ui | Настройки, тихий звук, HUD и пауза |
| FrameDispatch | Выпуск задания и раздельное владение выводом |
| Library | Каталог SD/ZIP, активная ROM, MMC5 session |
| Telemetry | Игровой шаг и наблюдение завершённых кадров |
| Console | UART-команды и кадровый ввод |

Main вызывает переходы только после требуемого join/sourceDone. Ошибка удерживает заимствованные ресурсы. Проверка структуры включает сравнение раскрытых C++-токенов; фактические source locations и ELF проверяются новой SDK-сборкой.
