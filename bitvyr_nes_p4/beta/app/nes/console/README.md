# Буферизация UART

BufferedUart оборачивает закреплённый SDK VFS getter и передаёт ограниченные TX-пачки без изменения публичного протокола команд.

Рекурсивный mutex защищает общий TX-контекст; ранний startup/ISR используют исходный VFS.

Статическое состояние живёт до reboot. Flush имеет срок; ошибка или рекурсия не ведут к самопечати через тот же proxy.

ESP-IDF6.1 UART/VFS, linker --wrap. Проверка — сборка закреплённого SDK и целый журнал без повреждённых строк.
