# Приложение консоли

NesApp связывает библиотеку, настройки, меню и FramePipeline; интерфейс — run и внутренние переходы экранов.

Main/CPU0 владеет Board, ROM и интерфейсом. Worker/CPU1 заимствует Machine до done/join.

Постоянные контексты и ограниченные кадровые слоты; горячий цикл не создаёт ROM-копий. При неизвестном владельце ресурсы удерживаются до reboot.

Core, board_support и стандартная библиотека; проверка — native-пакеты и аппаратный игровой маршрут.
