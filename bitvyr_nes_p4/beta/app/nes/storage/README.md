# Библиотека SD и ZIP

GameLibrary индексирует nes_rom, ZipArchive читает NES-запись ZIP и проверяет размер/CRC.

Только Main; Worker получает уже загруженную неизменяемую ROM.

Каталог имеет generation, загрузка перепроверяет идентичность и границы. Один активный образ хранится в PSRAM; ошибки чтения не создают частично готовую игру.

Стандартные файловые API, compression и ESP heap-адаптер при ESP_PLATFORM. Проверка — ZIP и библиотечные native fixtures.
