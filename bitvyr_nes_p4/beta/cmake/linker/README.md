# Размещение кода P4

Единственный набор LDFRAGMENTS подключён в app/nes/CMakeLists.txt. Горячая цифровая эмуляция размещается в HP SRAM, холодные setup/teardown и полный Main-растеризатор — в Flash; отдельный fetched pixel kernel остаётся внутренним.

Имена unity-объектов и mangled symbols относятся к конкретному C++17-профилю. Изменение состава TU требует SDK link/map проверки IRAM/DRAM и новой аппаратной квалификации. Эти правила принадлежат адаптеру платы, переносимый Core linker-скриптов не включает.
