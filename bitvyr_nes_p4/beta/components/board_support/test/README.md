# Проверки HID

HostHidTests проверяет дескрипторы и игровые маски Xbox без радиотранспорта.

Один native-процесс, аппаратные задачи не запускаются.

Fixtures встроены в исходник; ROM и сохранения пользователя не нужны.

Тот же HidGamepad.cpp, стандартный C++17. Запуск — через curated native CTest.
