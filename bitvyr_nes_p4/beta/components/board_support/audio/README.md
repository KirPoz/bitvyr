# Кодек и I2S

Audio.cpp настраивает ES8311, усилитель и выдачу PCM48кГц через I2S DMA.

Main подаёт готовые отсчёты; DMA callbacks обновляют атомарные счётчики.

Громкость0..100; тихие исходные настройки и mute применяются до игры. Состояние физического DMA учитывается отдельно от отправленных блоков.

I2C/I2S SDK и BoardState; аппаратно проверяются непрерывность и действующая громкость.
